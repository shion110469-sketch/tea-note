# 紅茶ノート（試作版）

MyTeaPal を参考にした、日本語の紅茶アプリ。リサーチ：[research/紅茶アプリ市場.md](../../research/紅茶アプリ市場.md)

## 機能
| 画面 | 内容 |
|---|---|
| 起動時 | 初めて開いた端末ではオンボーディング（使い方とメリット、ニュースの紹介を含む5枚）。2回目以降は新しく起動したときだけスプラッシュを約1秒表示（バックグラウンドから戻ったときは出さない）。ガイドタブから使い方を再表示できる |
| ホーム | 在庫からのおすすめ、次に試したい茶葉の提案、在庫が少ない茶葉の通知、記録（「最近」と「評価トップ3」を切り替え。トップ3はプロの総合点、ノーマルは★を点数に換算して順位付け） |
| タイマー | 茶葉ごとの温度・量・湯量・蒸らし時間（分・秒を1秒単位で設定）。完了時にチャイム（閉じるまで最長1分、マナーモードでも鳴る。Android はバイブも）・通知、在庫の自動減算 |
| 記録 | テイスティング記録。ノーマル（★評価・味タグ・香り/渋み/コク）とプロ（下記）を切り替え。共通で在庫から選ぶ茶葉・飲み方・日付・抽出条件（温度・茶葉量・湯量・蒸らし）・メモ・写真3枚まで。名前・メモ・味での検索と並べ替え、飲んだ日がわかる月カレンダー（日付をタップでその日の記録に絞り込み）、好みの分析、統計（`#/stats`：杯数、月ごとの杯数と平均★、よく飲む紅茶、好きな味とその変化、飲み方、プロの記録の平均点） |
| 茶葉・在庫 | 茶葉の登録・編集、在庫管理（補充、1杯ずつ減らす）、バックアップ（茶葉は手入力で登録） |
| ニュース | 紅茶関連ニュースの一覧とキーワード別の絞り込み（下記）|
| ガイド | 初心者向けの楽しみ方（基本の淹れ方、ティーバッグ、ミルクティー、アイスティー、フレーバー、和紅茶、カフェインを控えたいとき、保存） |

### 紅茶のニュース
- GitHub Actions（[.github/workflows/news.yml](.github/workflows/news.yml)）が6時間ごとに [scripts/fetch-news.ps1](scripts/fetch-news.ps1) を実行し、Google ニュースの RSS から「紅茶」「和紅茶」「アフタヌーンティー」の見出しを取得して `news.json` を更新する
- キーワードごとに最大15件、合計40件、30日以内の記事。見出し・配信元・日時・リンクのみを保存し、本文は各配信元のサイトで読む
- アプリの「ニュース」タブ（`#/news`）に一覧とキーワード別の絞り込みを表示
- Google ニュースの RSS は「個人的・非商用の利用」に限られるため、個人利用の前提で使う
- 手動で更新したいとき：GitHub の Actions タブ →「Update tea news」→「Run workflow」

### プロのテイスティング記録
- 抽出条件はノーマルと共通（タイマーから記録すると自動入力、茶葉を選ぶと淹れ方で補完、空欄の項目は記録しない）
- 茶葉のグレード、水色（色見本＋澄み具合）、香りの表現（16種）、茶殻の色
- 品質評価：外観・水色・香り・味・余韻を各10点 → 合計×2で100点満点。一覧にレーダーチャートで表示
- 味の特徴（強さ5段階）：渋み・苦味・甘み・コク・酸味・香りの強さ
- 好みの分析用に、総合点から★（90点以上で★5…）、香りの表現から味タグ（マスカット→フルーティーなど）を自動で付ける
- 前回使ったモードを覚え、過去の記録は記録したときのモードで開く

### 好みの提案のしくみ（[js/recommend.js](js/recommend.js)）
- ★4〜5の記録はプラス、★1〜2はマイナスとして、味タグと茶葉の種類ごとに点数を積み上げる
- 在庫からのおすすめ：好みとの一致、その茶葉の平均評価、しばらく飲んでいないかどうかで並べる
- 次に試したい茶葉：[js/data.js](js/data.js) の茶葉カタログから、まだ登録・記録していない種類を好み順に提案（記録が2件未満のときは初心者向けの茶葉）

## ストア版（Android・準備中）
Google Play で公開するための版。中身は Web 版と同じファイルで、[js/platform.js](js/platform.js) が動いている場所を見分けて切り替える。

| | Web 版 | ストア版 |
|---|---|---|
| 料金 | すべて無料 | 基本無料＋紅茶ノート Pro（月350円・最初の1週間無料） |
| Pro の機能 | 制限なし | プロのテイスティング記録、写真3枚（無料は1枚）、統計 |
| 購入リンク（PR） | なし | 在庫が少ない茶葉・次に試したい茶葉・茶葉の詳細から Amazon の検索結果を開く |
| ニュース | Google ニュース | 商用で使える取得元が決まるまで非表示 |

- 設定は [js/platform.js](js/platform.js) の `STORE_CONFIG`（RevenueCat の公開キー、Amazon のトラッキング ID、ニュースの取得元など）
- Pro の状態と購入は [js/pro.js](js/pro.js)。Google Play の定期購入を RevenueCat で確認し、最後の状態を覚えてオフラインでも使えるようにする。Pro をやめても、プロで記録済みのものは見る・編集できる
- ブラウザでの確認：`http://localhost:8080/?store` で開くとストア版として動く（購入・復元・解約は確認ダイアログで試せる）
- プライバシーポリシー：[privacy.html](privacy.html)（https://shion110469-sketch.github.io/tea-note/privacy.html）
- タイマー：アプリ版は終わる時刻に通知（音・バイブ）を予約するので、画面を閉じていても知らせる（[js/timer.js](js/timer.js) の `NativeAlarm`）

### Android アプリの組み立て
- 必要なもの：Node.js、Java 21（Microsoft OpenJDK 21）、Android Studio（Android SDK）。Android Studio 付属の Java は新しすぎて使えない
- 組み立て：`powershell -ExecutionPolicy Bypass -File scripts\build-android.ps1`（`-Release` で Google Play 用の AAB）
  - フォルダー名に日本語があると組み立てツールが動かないため、スクリプトが `T:` ドライブを割り当ててから組み立てる
  - Web 版のファイルを `www/` にまとめ、プラグイン（[scripts/native-entry.js](scripts/native-entry.js)）を `www/js/native.js` に1つにまとめてから Android プロジェクト（`android/`）に反映する
- エミュレーターに入れる：`adb install -r T:\android\app\build\outputs\apk\debug\app-debug.apk`
- アプリ ID：`jp.teanote.app`

## スマホで使う
1. スマホのブラウザで https://shion110469-sketch.github.io/tea-note/ を開く
2. ホーム画面に追加する
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「ホーム画面に追加」または「アプリをインストール」
3. 以降はアイコンから起動。一度開けばオフラインでも動く

更新を配信するときは、ファイルを変更して `sw.js` の `VERSION` を上げ、GitHub に push する（GitHub Actions がニュースを自動で push するので、先に `git pull --rebase`）。
スマホのアプリは、次に開いたとき（バックグラウンドから戻ったときも）に新しい版へ自動で切り替わる（`js/update.js`。タイマー作動中や入力中は「更新」ボタンを表示）。

## 起動方法（PCで開発するとき）
```
powershell -ExecutionPolicy Bypass -File serve.ps1
```
ブラウザで http://localhost:8080 を開く（Node.js / Python は不要）。
※ `index.html` を直接開いても動きますが、ニュースとオフライン機能は localhost か HTTPS で開いたときだけ動きます。

## 技術構成
- HTML / CSS / JavaScript のみ（ビルド不要）
- データは端末のブラウザ内に保存（茶葉・記録は localStorage、写真は長辺1280pxに縮小して IndexedDB）。「茶葉・在庫」画面の下から写真を含めてJSONで書き出し・読み込みできる

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ヘッダー・下部タブ） |
| `style.css` | デザイン（ライト／ダーク対応） |
| `js/platform.js` | Web 版／ストア版の見分けと、ストア版の設定 |
| `js/pro.js` | 紅茶ノート Pro の状態と購入（ストア版） |
| `privacy.html` | プライバシーポリシー |
| `js/data.js` | 味タグ、茶葉の種類、淹れ方プリセット、提案用カタログ、ガイド本文 |
| `js/store.js` | データ保存（localStorage） |
| `js/photos.js` | 記録の写真（縮小して IndexedDB に保存、バックアップへの書き出し・読み込み） |
| `js/recommend.js` | 好みの分析と提案 |
| `js/timer.js` | 抽出タイマー |
| `js/app.js` | 画面の描画と操作 |
| `js/intro.js` | オンボーディングとスプラッシュ |
| `js/update.js` | オフライン対応の登録と、新しい版への自動切り替え |
